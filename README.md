📅 Year Progress Menu Bar App For MacOS

A lightweight macOS utility that lives in your menu bar and gives you a visual representation of how much of the year has passed. Perfect for staying motivated or realizing just how fast time is flying.
🚀 Features

    Live Progress: Real-time percentage of the current year.

    Minimalist Design: Sits quietly in your menu bar without cluttering your menu bar.

    Native Swift: Built with SwiftUI for the best performance on macOS.

📥 Installation

    Go to the Releases page.

    Download the latest .zip file.

    Open the .zip and drag Year Progress Menu Bar to your Applications folder.

    [!IMPORTANT]
    Note for macOS Users: Because this app is not signed by a registered Apple Developer, you may see a warning that it "cannot be opened."
    To fix this: Right-click the app in your Applications folder, select Open, and then click Open again in the pop-up window.
